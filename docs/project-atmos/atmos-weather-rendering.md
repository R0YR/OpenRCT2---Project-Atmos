# Weather rendering fixes (0.2.0)

Cloud density is owned by `BuildCloudPlanes`. The weather transition remains eased over roughly 30 seconds; all workers consume one immutable `CloudFrame`. Weather now increases configured coverage by at most 25%, capped at 60% unless the user explicitly selects a higher value. Precipitation may supply scattered banks up to 30% coverage when the slider is zero. A 100% slider explicitly selects overcast, independently of weather. Precipitation no longer adds 40 percentage points of visible opacity. Snow/heavy snow/blizzard add 6/10/14% fog, respectively. The storm preset uses 50% coverage and 80% opacity. Existing saved slider values are respected, including previously selected high cover.

Cloud noise is sampled in continuous map coordinates through `CloudMapPoint`, the inverse of the engine's isometric projection for all four rotations. The old cloud edge fade incorrectly measured distance from the map using the ground at the screen pixel: an elevated cloud was clipped differently after rotation. Cloud opacity now measures the actual cloud-plane position at the configured altitude. Ground fog and cloud shadows retain their own ground-plane boundary. Wind remains integrated in map space, with no camera-dependent state reset.

Lightning retains the existing deterministic strike path and timing. A stronger neutral-white core and halo overcome the blue background during bright strikes. Local scattering whitens surrounding cloud pixels more strongly than distant ground; the UI and unused pixel channel remain unchanged. The effect remains controlled by lightning strength and the game's disable-lightning option.

Validation: `scripts/test-atmos-weather.py` compiles the production projection, coverage and lightning helpers with MSVC. It passes 1280 map/altitude/rotation/zoom round trips, 2424 coverage combinations, monotonic bounded storm transitions, white bolt cores, cloud illumination, disabled intensity, UI preservation and alpha-channel preservation. Final full application build and integrated park inspection are separate checks; these helper tests do not claim live visual verification of every weather combination.
